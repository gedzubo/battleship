# Battleship

> **Learning project — work in progress**

A multiplayer Battleship game built with Ruby on Rails. Two players take turns firing at each other's boards in real time, with ship placement, a live chat, game history with replay, and a leaderboard.

Built to explore Rails defaults: Hotwire (Turbo + Stimulus) for real-time updates, ActionCable over SQLite via Solid Cable, Rails built-in authentication, and Tailwind CSS for styling. No unnecessary gems.

## Getting started

```bash
bundle install
bin/dev
```
